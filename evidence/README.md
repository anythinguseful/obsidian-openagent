# Open Agent — Evidence

Raw, reproducible evidence supporting historical audits and release hardening.

- `audits/` contains parser logs, regression matrices, patch evidence, and
  security-audit support files.
- `paket-c/` contains the PDF/dependency hardening plans, reports, release
  logs, checksums, manifests, and browser-matrix outputs.

Read the curated audit narrative first in [`../docs/audits/`](../docs/audits/).
Evidence is retained separately so documentation remains readable while every
technical claim can still be traced to its original output.
