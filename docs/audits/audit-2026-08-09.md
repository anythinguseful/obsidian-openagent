## 3. Dead code

### 3a. CSS (styles.css 178,6 KB; 485 class `oa-*`)
Scan naive memberi 43 kandidat, **43 di antaranya dibantai sebagai false-positive** lewat bukti template dinamis:
`oa-color-${c}` (settingsTab:2040/2207), `oa-tok-${tok.t}` (code-block:52), `oa-loader-${size}` (loader:36), `oa-msg-${role}` (ChatApp/message/quickask), `oa-sysmsg-${kind}` (system-message), `oa-preview-op-${op}` (preview-diff), `oa-prompt-action-${variant}` (prompt-input), `oa-searchbox--${v}` (search-field), `${cls}-wrap` (settingsTab:2790 → `oa-skills-search-wrap`, `oa-hub-search-wrap` Hidup — dipakai probe F31).

Sisa kandidat mati **sesungguhnya**: cuma
- `oa-selbar-rooted`
- `oa-app-only`
- `oa-app-scoped`

Ketigaya tak ada aplikator di `src/` maupun harness — **tapi** komentar styles.css di sekitarnya berbicara seolah load-bearing ("Keep every selbar rule .oa-selbar-rooted…", field-reset layer). Vonis: **jangan dihapus otomatis** — verifikasi manual render satu-satu di Obsidian asli lebih dulu (risiko bayang-bayang reset umbrella), atau biarkan (biaya pemakaiannya kecil). Hemat nyata CSS terbesar bisa datang dari minify (P3, ±50KB), bukan dari menghapus selector.

## 4. Async/leak posture — kuning muda, bukan merah
- `setInterval/setTimeout`: 32 pemasang vs 12 pembersih — sampel yang kuperiksa pasangan scoped-React dengan cleanup (attachMenu, selection bar) benar semua. Selebihnya fire-and-forget UI timers (notice auto-hide, spinner) — pola Obsidian-lazim, view dispose tidak membocorkan window karena closure mati bersama view. Vonis: **watch item**, tidak ada tindakan.
- `addEventListener` 94 vs `removeEventListener` 26 — mayoritas listener DOM di-*scope* useEffect dengan cleanup berpasangan (154/1170 dkk. terbukti berpasangan). React-render register (`addEventListener` di render body tanpa ref) tidak ditemukan. Idem watch item.
- Listeners Obsidian resmi (`registerEvent/registerDomEvent`) dipakai main/ChatView — aman dari lepas-disable plugin.
