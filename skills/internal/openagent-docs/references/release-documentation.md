# Release documentation checklist

1. Update `RELEASES.md` with a concise user-facing summary.
2. Create `releases/vN/openagent-vN-final-report.md` with verified gates and hashes.
3. Keep raw logs/checksums in the release/evidence location, not the changelog.
4. Verify version metadata and run the full release pipeline.
5. Do not rewrite a published release for later source changes; make a new version.
