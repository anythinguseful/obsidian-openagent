# Arena Bug-Diagnosis Adapter

Use the pinned `diagnosing-bugs` vendor skill as an evidence discipline. Replace
its assumed `CONTEXT.md` with `AGENTS.md`, `docs/working-agreement.md`, and the
relevant audit/reference note. Do not run its human-in-the-loop shell template
without explicit user approval. Arena diagnosis must finish with a reproducible
witness, an appropriate regression guard, and a concise Lessons-log addition
when the finding establishes a reusable project rule.
